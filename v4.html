What this is

Measures how much TVT is truly incremental per title on Tubi — TVT that would not have happened on a substitute title if this one weren't in the catalog. Content decisions (licensing, promotion, originals investment) hang on this number.

v4 changes from v1

  • Session-day anchored controls (eliminates immortal time bias)
  • power_viewer + qual_session_bucket features added to propensity
  • Pre-event TVT >= 15 min filter (eliminates ratio blow-up from low-TVT viewers)
  • Substitution rate clipped to [-1, 2] per pair (allows super-additive and suppressive signals)
  • Per-genre X-learner (GBR per genre_bucket, title-level aggregation before fitting)
  • Model persistence to DBFS (/dbfs/FileStore/phase3_models/)
  • Timeframe: Jan–Mar 2026

How to read this page

  • Green — metric inside manage-to target; nothing to do.
  • Amber — outside target but not ship-blocking.
  • Red — outside target and degrades trust; see Gaps tab.
  • Ship gate — anchor agreement threshold that decides whether v4 is usable.

Five stages feed the daily incremental-TVT fact table. Click any stage to expand.

P1 · Event definitions —

What it does: Builds staging tables from raw video_session + rightsline_right: completion events, catalog expirations, rewatch rates.

Key assumptions:

  • Viewer grain = COALESCE(user_id, device_id)
  • 28-day abandonment window uniform across content types

Outputs: stg_completion_events_v1, stg_catalog_expirations_v1

—
P2 · Matching & propensity —

What it does: Logistic propensity per (content_type x genre_bucket) cell; session-day anchored nearest-neighbor matching within strata; emits 28d TVT deltas.

v4 changes: Added power_viewer + qual_session_bucket; session-day anchor fixes immortal-time bias; pre_event_tvt >= 900s filter.

Outputs: matched_event_pairs_v4, event_deltas_v4

—
P3 · Substitution model —

What it does: Predicts per-title substitution rate s(T). Per-genre GradientBoostingRegressor on title-level aggregated s. Rewatch dampening s * (1 - rewatch_rate).

v4 changes: Per-genre models (not per-content_type); title-level aggregation before fitting; pair-level clipping [-1, 2]; Jan-Mar 2026 scope; model persistence to DBFS.

Outputs: title_substitution_observed_v4, title_substitution_predicted_v4, title_substitution_dampened_v4

—
P4 · Anchor validation —

What it does: Checks whether per-user anchor (completer delta) and expiration anchor (catalog removal delta) produce overlapping 95% CIs per title.

v4 changes: Both anchors apply same pair-level clipping [-1, 2] and pre_tvt >= 900s. Comparison on same formula: s = 1 - (delta_tvt / pre_event_tvt).

Outputs: expiration_deltas_v4, anchor_agreement_v4

—
P5 · Daily rollup —

What it does: Aggregates per-title dampened substitution rates into daily fact table by cohort x content_type. incremental_tvt = tvt_retained * (1 - s_dampened).

v4 changes: Reads from title_substitution_dampened_v4; no session_initiation_credit (skipped for v4 fast iteration); Jan-Mar 2026.

Outputs: fct_content_incremental_tvt_daily_v4

Jan-Mar 2026 (90d)

Grouped by severity. Each item names what to fix, which metrics move, and expected lift.

Red — blocks ship

Anchor agreement below target
P4 · ship gate
What's happening: Per-user anchor (completers = heavy viewers, mean s ~0.73) is structurally higher than expiration anchor (all watchers including casual, mean s ~0.57). The ~16pp systematic gap is a population difference, not a method error.
Metrics that move: anchor_agreement, avg_disagreement_pp.
Options: (a) Accept the gap as structural and calibrate thresholds per-anchor, (b) restrict both anchors to the same viewer population (heavy-viewer subset), or (c) weight agreement by data density.

Amber — on the backlog

Post-match SMD violations on activity features
P2 · matching quality
What's happening: Two SMD violations exceed the |0.10| threshold: sessions_28d (SMD = 0.265) and tvt_28d_sec (SMD = 0.261). Treated viewers average 852 sessions and 19.9M sec TVT in 28d vs controls at 470 sessions and 2.2M sec — a ~9× TVT gap and 1.8× session gap. The imbalance is uniform across genres (kids lowest at 4.3×, documentary/drama worst at 10–12×). Propensity matching on tenure_bucket + is_registered + logit caliper does not absorb the fundamental activity difference between completers and non-completers.
Metrics that move: max_post_match_smd, smd_violation_count, downstream delta estimates.
Options: (a) Add tvt_28d_sec quartile as an exact-match blocking variable, (b) apply IPW weighting post-match to rebalance, or (c) restrict treated pool to a TVT band where controls are available at comparable density.
Wide confidence intervals in observed substitution rates
P3 · precision
What's happening: Most titles have CI halfwidths exceeding the 0.25 dampening threshold, routing them to the predicted model even when observed data exists (e.g., Coraline: s_observed = 1.66, CI halfwidth = 0.97, dampened to s_predicted = 0.75). The 0.25 threshold is too strict given pair-level variance, causing the model to override direct observation for ~74% of observed-eligible titles.
Metrics that move: titles_observed_eligible effective utilization, dampened s accuracy.
Options: (a) Relax halfwidth threshold (e.g., 0.50) to trust observed when available, (b) use observed whenever model_source_eligible = true regardless of CI width, or (c) blend observed and predicted weighted by inverse CI width.
Two-anchor system (no experiment anchor)
P0/P1 · structural
What's limited: Zero credible past addition experiments found in statsig_experiment_bydevice. v4 ships two-anchor; correlated bias uncheckable.
Fix: Run a controlled content-addition experiment in Q3 2026.
