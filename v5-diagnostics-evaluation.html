Grading Criteria

Diagnostic Checks (8 total)

  • 1. SMD Pre-TVT|SMD| < 0.10
  • 2. VR Pre-TVT0.8 ≤ VR ≤ 1.25
  • 3. Match Rate (pipeline)≥ 70%
  • 4. ML Score Distance≤ 0.20 (log-odds)
  • 5. Pre-TVT Ratio[0.8, 1.2]
  • 6. A/A Test In-Sample|d| < 0.10
  • 7. A/A Test Out-of-Sample|d| < 0.10
  • 8. Rosenbaum γ ≥ 1.5Γ ≥ 1.5 (sign test)

Grade Assignment

  • HIGH≥ 6/8 checks pass AND SMD pass
  • MEDIUM4–5 checks pass, or fails SMD hard gate
  • LOW< 4 checks pass

Hard Gates (title-level)

  • SMD Pre-TVT|SMD| < 0.10 (caps at MEDIUM if fail)
  • Match Rate (pipeline)≥ 70% (whole pipeline)
  • A/A Out-of-Sample|d| < 0.10 (pre-trend free)

Pipeline-Level KPIs

  • Treated Match Rate≥ 70%
  • Total Matched Pairs≥ 100K
  • SMD Pass Rate (all titles)≥ 90%
  • A/A Out-of-Sample Pass≥ 80% titles
  • Pre-TVT Ratio[0.8, 1.2]

Metric Definitions

  • SMD Pre-TVT: Standardized mean difference in timestamp-based 28-day pre-event TVT between treated and control groups. Measures mean balance.
  • VR Pre-TVT: Variance ratio of treated vs control pre-event TVT. Measures distributional shape balance. Target [0.8, 1.25].
  • Match Rate: Fraction of eligible treated completers that found a valid CEM+caliper match. Target ≥ 70%.
  • ML Score Distance: Mean |logit_treated − logit_control| across all pairs. Measures within-block affinity similarity. Target ≤ 0.20.
  • Pre-TVT Ratio: Mean(treated_pre_tvt / control_pre_tvt). Ideal = 1.0. Measures overall balance achieved by CEM blocking.
  • A/A Test In-Sample [fv_ts−28d, fv_ts): Cohen's d on the matching covariate window. Should be ~0 if CEM worked correctly.
  • A/A Test Out-of-Sample [fv_ts−56d, fv_ts−28d): Cohen's d on held-out pre-period. Should be ~0 if matching doesn't capture pre-trends.
  • Rosenbaum Γ: Sensitivity to hidden bias. How strong an unmeasured confounder must be to explain the effect. Γ=2 means confounder doubles treatment odds.

CEM Blocking Variables (9)

  • content_type: MOVIE (all titles in v5 scope)
  • genre_bucket: Comedy, Action, Kids, Drama, Other
  • user_segment: Power Viewer, New (M1), Active non-power (Retained), Non-active (Reactivated)
  • tvt_bucket: 0-1h, 1-5h, 5-15h, 15-40h, 40h+
  • visit_days_bucket: 0d, 1-2d, 3-7d, 8-14d, 15-21d, 22-28d
  • sessions_bucket: 0, 1, 2, 3, 4, 5+
  • tenure_bucket: lt_30d, 30_90d, 90_365d, 365d_2y, gt_2y
  • is_registered: TRUE / FALSE
  • is_fan_of_title_fandom: TRUE / FALSE (viewer has points in any of title's fandoms)
