What this is

Measures how much TVT is truly incremental per title on Tubi — TVT that would not have happened on a substitute title if this one weren't in the catalog. Content decisions (licensing, promotion, originals investment) hang on this number; without incrementality, top-streaming titles get credit for viewing that would have happened anyway.

How to read this page

  • Green · metric is inside its manage-to target; nothing to do.
  • Amber · metric is outside target but not ship-blocking; improvement is on the backlog.
  • Red · metric is outside target and degrades trust in the number; see Gaps tab for the fix.
  • Ship gate · the primary metric that decides whether the model is usable for decisions.
  • Manage-to target · the number we want to drive each metric to over successive runs.

Five stages feed the daily incremental-TVT fact table. Click any stage to expand its model, assumptions, and outputs.

P1 · Event definitions —

What it does: Builds four staging tables from raw video_session + rightsline_right: completion events, catalog expirations, past-experiment inventory (empty in v2), and 12-month rewatch rates per title.

Model / technique: Parameterized SQL with per-content-type TVT thresholds (completion = TVT ≥ 70% × duration; abandonment = 28-day trailing silence).

Key assumptions:

  • 28-day abandonment window is uniform across content types accepted
  • Viewer grain = COALESCE(user_id, device_id) — both registered and anon included accepted
  • Series-completed = "finished ≥70% of all cataloged episodes" (very high bar) under review
  • Series event_date = last_view_date — entire binge period falls in pre-event window new finding · contaminates denominator

Primary outputs: stg_completion_events_v1 (9.6B rows), stg_catalog_expirations_v1 (4,964 rows), title_rewatch_rate_v1.

—
P2 · Matching & propensity —

What it does: Learns each viewer's propensity to complete title T; nearest-neighbor matches treated (completers) to controls (non-completers) within strata (content_type × genre × event_month × is_registered). Emits per-pair 60/90/120-day TVT deltas.

Model / technique: sklearn.LogisticRegression per (content_type × genre_bucket) cell; caliper 0.1 on logit scale; per-stratum matching.

Key assumptions:

  • Per-cell propensity is well-specified with the feature set (tenure, TVT buckets, genre-share) under review · AUC 0.96+ suggests leakage
  • Post-match balance achievable at SMD ≤ 0.1 within 3600s warehouse timeout broken · 39 residual violations
  • Donor-screen (30-day TVT threshold) excludes viewers with outside-the-model substitutes under review · near-inert

v2 change: Added pre_event_tvt_total_sec column to event_deltas_v1 — total user TVT across all titles in the pre-event window. Used as the denominator in P3.

Primary outputs: matched_event_pairs_v1 (73,578 pairs at 1% sampling), event_deltas_v1, expiration_deltas_v1.

—
P3 · Substitution model —

What it does: Predicts per-title substitution rate ŝ(T) — the share of a treated viewer's post-event TVT that would have happened on a substitute title. Applies rewatch dampening ŝ × (1 − rewatch_rate).

Model / technique: sklearn.GradientBoostingRegressor per content_type, asymmetric X-learner (treated-arm regressor only — controls have no T to substitute against).

Key assumptions:

  • Per-title TVT is a valid denominator FIXED in v2 — denominator swapped to total user TVT. Substitution rates now in [0, 1] range.
  • Rewatch rate per content_type is the right dampening granularity under review · potential double-counting for series
  • 2-hour session-initiation window best tracks same-session follow-on TVT accepted · Spearman-stable
  • ŝ > 1.0 should be clipped before dampening 341 titles (5.1% TVT) · v3 fix planned

v2 changes:

  • Outcome formula now uses total user TVT: clip(1 − delta_tvt / pre_event_tvt_total_sec, −1, 2)
  • Observed substitution rate denominator aligned to total TVT
  • RMSE improved from 0.74/0.89 → 0.44/0.53 (movie/series)
  • Per-user avg substitution rate: 0.755; expiration avg: 0.549

Primary outputs: title_substitution_observed_v1, title_substitution_predicted_v1, title_substitution_dampened_v1, session_initiation_credit_daily_v1.

—
P4 · Anchor validation —

What it does: Checks whether two independent anchors — the per-user substitution model and the catalog-expiration natural experiment — produce consistent estimates for each title.

Model / technique: CI overlap test on per-title substitution rates (original gate); rank-based agreement metrics added in v2 as proposed alternative gate.

Key assumptions:

  • Per-user and expiration anchors share no systematic bias structural -20.6 pp bias identified — per-user measures completers (avg ŝ=0.755), expiration measures all viewers (avg ŝ=0.549). Different causal questions.
  • CI overlap at 95% is the right agreement test under review · rank-based gate proposed
  • Denominator = titles with both anchors measurable (n ≥ 30 matched pairs each) accepted

v2 findings:

  • CI-overlap agreement: 17.8% → 46.4% (all months) → 35.7% (data-complete, Jan+Feb only)
  • Structural population mismatch: consistent -20.6 pp bias across months
  • Filtering expiration anchor to completers made agreement worse (0.224)
  • Rank-based metrics: Spearman ρ = 0.37, same-half concordance = 65.5%, within ±1 quartile = 79.4%
  • Data truncation: Mar/Apr expirations lack complete 90d post-event windows

Primary outputs: anchor_agreement_v1 (15,644 rows, n_joint=718).

—
P5 · Daily rollup + memo —

What it does: Aggregates per-title substitution rates and session-initiation credits into a daily fact table by cohort × content_type, with weekly/monthly/YTD rollup views and a promo-sidebar slice.

Model / technique: SQL aggregation over title_substitution_dampened_v1 × session_initiation_credit_daily_v1; delta-method CIs; 10% flat one-shot rate (pending calibration).

Key assumptions:

  • Cohort bucket via release_decade proxies licensing-start-date cohorts under review
  • 10% one-shot rate is a stable-enough placeholder until calibrated under review
  • Delta-method CI is accurate enough for v2 headline numbers under review · bootstrap planned

v2 addition: vw_segment_decomposition_v1 — decomposes per-title pairs into amplified / substituted / suppressed / churned segments.

Primary outputs: fct_content_incremental_tvt_daily_v1 (3,706 rows), weekly/monthly/YTD views, vw_content_promo_sidebar_snapshot_v1, vw_segment_decomposition_v1.

Structural population mismatch between anchors
P4 · limits CI-overlap agreement ceiling
What's happening: Per-user anchor measures completers (high-engagement self-selectors, avg ŝ = 0.755). Expiration anchor measures all pre-expiration viewers (broader population, avg ŝ = 0.549). Amber · improvements on the backlog

Data truncation in Mar/Apr expirations
P2/P4 · inflates April estimates
What's broken: Mar/Apr 2026 expirations lack complete 90-day post-event windows (April expirations had only ~12 days of post-event data). This inflated April's expiration estimates and masked the structural bias.
Fix planned (v3): Use events from Jul 2025 through Feb 11, 2026 only (ensuring event_date + 90d ≤ 2026-05-12). Parameterize for future runs.
Metrics that move: anchor_agreement_ci, median_disagreement_pp.
ŝ > 1.0 not clipped before dampening
P3 · produces negative incremental TVT for 341 titles
What's broken: The X-learner is unbounded and produces ŝ > 1.0 for 341 titles (5.1% of TVT). Rewatch dampening accidentally masks some of these by pulling values below 1.0, but explicit clipping is methodologically correct.
Fix planned (v3): GREATEST(0.0, LEAST(1.0, substitution_rate_predicted)) before dampening.
Metrics that move: s_hat_above_1_fraction → 0%.
Expected lift: +0.63% aggregate (+4.5M hrs incremental TVT). Small but clean.
Rewatch dampening may double-count for series
P3 · methodology question for David
What's broken: Post-event window already captures rewatches in TVT (the delta measures ALL viewing including revisits to the same title). Dampening formula ŝ × (1 − rewatch_rate) then gives additional credit for rewatches. For series with 35–45% rewatch rates, this is a significant double-count.
Impact: Series dampening is the dominant lever — reduces ŝ by 35–45%. If this is a double-count, series incremental TVT is overstated.
Metrics that move: rewatch_dampening_effect_series, downstream TVT totals.
Series event_date = last_view_date contaminates pre-event window
P1/P2 · methodology question
What's broken: For series, event_date is the date the viewer finished the last episode. The entire binge period (potentially weeks/months) falls in the pre-event window, inflating the pre-event denominator and potentially contaminating matching features.
Impact: Unclear magnitude. For movies (single sitting, typically 1–2 days), this is not an issue.
Metrics that move: Potentially xlearner_rmse_series, series substitution rates.
Tighten post-match balance
P2 · caveat-only today
What's broken: 39 residual SMD violations on continuous activity features (max 0.498 on days_active_30d). Balance gate accepted per NOTES §4.2 option (c).
Metrics that move: max_post_match_smd, smd_violation_count.
Expected lift: all SMDs ≤ 0.1; removes a memo caveat.
