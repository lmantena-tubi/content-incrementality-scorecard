28-day variant — two things to read the numbers with:
Now on the full window (no extrapolation). This run covers all Aug 8–14 events — Aug 14 + 28d = Sep 11, and video_session is complete well past that. Δ/viewer is therefore estimated and applied over the same Aug 8–14 span, so the population-extrapolation caveat carried by the earlier Aug 8–10 build no longer applies. The pair set is identical to the published 7-day run (2,767,736 pairs), which also means v11_step10_weights_28d now reproduces v11's weights exactly — per-cell de-dup drift is ~0, not the 1–30% the truncated build carried.
1. The de-duplication ladder is still 7d-calibrated. Its weight constants were chosen to spread a 7-day post across titles; over 28 days a viewer touches more titles, so the true 28-day weight is smaller and the Incr TVT shown here is an upper bound (magnitude quantified by validation V5 in v11_step5_8_tvt_28d). Retuning the constants is out of scope — changing the weight and the window together would confound the comparison.
2. The control screen ends Aug 21. The control pool's no-contamination window covers the 7d post end only, so a control can start the show in post-days 8–28 — this biases the 28-day Δ downward (conservative); bounded by the _sens_ sensitivity tables.
The 7d-vs-28d contrast is on the “7d vs 28d (Top 100)” tab — both windows computed in one scan over this one pair set (phase3_window_comparison_v11_28d_tvt / _ivt), so the comparison is exact rather than a cross-run difference.

TVT incrementality (delta build). Everything is built from the per-viewer simple delta — no additive-proportional rate. Δ/viewer = net total (on+off) TVT, treated − matched control, hours per viewer (winsorized, from phase3_title_segment_simple_delta_v11_tvt); Δ/viewer colour = sign (green positive, red negative). Incr TVT = Σ(Δ/viewer × segment viewers × per-title weight) across segments (hours), where viewers = full-US ≥5-min organic first-session count (phase3_title_segment_viewers_v11) and the weight is computed per (title × segment) from that show’s own matched-pair viewer distribution on the shared 7d pre-TVT de-duplication ladder, recomputed on the 28-day pair set (phase3_title_segment_applied_weight_v11_28d, step10_28d) — averaging each matched viewer’s ladder weight, so two shows in the same segment differ when their viewers pre-watched different amounts. Pooled per-segment fallback: 0.352 Retained, 0.361 New (M1), 0.476 Reactivated, 0.145 Power Viewer. Confidence is shown per segment (11-check diagnostic grade, per title×segment). The Rate column = Incr TVT ÷ actual title TVT (overall title-level rate). Avail Sep 15 = title live in US catalog through Sep 15 2026 (content.content_availability).

Each point is one (series × segment) cell. X = Δ/viewer measured over the 7-day post window, Y = the same cell over the 28-day post window, with 95% CI error bars on both axes (horizontal = 7d CI, vertical = 28d CI). Both windows come from one scan over one identical pair set (phase3_window_comparison_v11_28d_tvt / _ivt, step 8c), so the contrast is exact — not a difference between two separately-built dashboards. The dashed diagonal is 28d = 7d: a point above it means the extra 21 days added measured incremental viewing; on it means the effect was fully captured inside 7 days.
“Top 100” = the 100 series with the largest 28-day Incremental TVT across all segments (Σ Δ/viewer × segment viewers × per-title de-dup weight — the same quantity the TVT Incrementality tab ranks on), or by Aug 8–14 title TVT if you switch the basis. A series is selected once on its catalog-wide rank and then appears in whichever of the four segment charts have a reportable cell, so the four charts share one title set rather than four different ones.
Reading the spread: the 28d CI is wider by construction (more post days, more variance per viewer), so cells can move up and still not separate from zero. The sig flags in the tooltip say whether each window's CI excludes zero. And per the caveat above, 28d Incr TVT is an upper bound — the de-dup ladder is 7d-calibrated.
